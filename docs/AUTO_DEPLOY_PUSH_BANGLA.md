# পুশ করলেই অটো ডিপ্লয় – VPS সেটআপ গাইড (বাংলা)

লোকাল থেকে কোড আপডেট করে `main` (বা `master`) ব্রাঞ্চে **push** করলেই সার্ভারে অটোমেটিকভাবে:

- কোড আপডেট হবে
- Node.js build চালাবে
- Database migration রান হবে
- Backend restart হবে

**সাইটে সম্পূর্ণ ডকুমেন্টেশন:** Admin Dashboard → SuperAdmin Dashboard → **Omni Setup on Server** (ধাপ ২: GitHub Secrets সেটআপ)
